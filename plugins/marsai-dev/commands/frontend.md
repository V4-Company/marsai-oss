Dispatch the `marsai-dev:frontend-engineer` agent for the task: $@

Pass in the prompt what to deliver, the acceptance criteria, the design when there is one, the API contract and the existing code that serves as an example. If `$@` is empty, ask what to implement.

With the implementer's report in hand, follow the `marsai-dev:implement` skill from step 3: check the report, commit and review.
