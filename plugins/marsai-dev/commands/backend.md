description: "Dispatches the TypeScript backend implementer directly, without the routing of implement."
argument-hint: "[what to implement]"
---

Dispatch the `marsai-dev:backend-engineer-typescript` agent for the task: $@

Pass in the prompt what to deliver, the acceptance criteria, where to test and the existing code that serves as an example. If `$@` is empty, ask what to implement.

With the implementer's report in hand, follow the `marsai-dev:implement` skill from step 3: check the report, commit and review.
