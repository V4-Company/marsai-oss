# Start: product

This entry point is now `/marsai-core:marsai-mode`, the single way into any work: it sizes the work, keeps the path as a checklist and leads the person to the end, talking about what changes for whoever uses the product. It starts only when the person types it, so it cannot be started from here.

Tell the person, in their language, to type `/marsai-core:marsai-mode` followed by what they wrote after this command, and stop there.
