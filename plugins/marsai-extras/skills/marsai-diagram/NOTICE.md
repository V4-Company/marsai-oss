# Provenance and modifications

This is an unofficial V4 Company adaptation of [Diagram Design](https://github.com/cathrynlavery/diagram-design), by Cathryn Lavery, MIT licensed. Upstream plugin version: **2.6.76**. Source commit: **fda20afe92c69ba5f02fe1dee48c7b2502f004fe**. The full copyright and permission notice is in [LICENSE.txt](LICENSE.txt).

Bundled: the upstream type and layout references, example/template assets, accessibility helper, three import extractors, SVG exporter and standalone geometry/type verification scripts. Upstream repository maintenance tests and slash commands are excluded. Equivalent user operations route through the single MarsAI skill, including in hosts that do not install plugin commands.

V4 changes: separate skill/profile names; concise entrypoint with source ledger and bounded visual verification; ready V4/MarsAI profile; at least 9 px readable typography; template support for wide presets; reference precedence over historical examples; deployed/proposed status and uncertainty vocabulary; sequence notes/PAR and composited masks; expanded swimlane grammar; installed-relative verification paths; installation coexistence and geometry regression tests. Em dash punctuation is replaced with commas in this distribution. Historical examples remain illustrations and must be adapted to the effective profile and current references.

Upstream guidance is retained in [UPSTREAM.md](UPSTREAM.md) with the changed first-use flow and packaged verification paths. This package does not claim endorsement by Cathryn Lavery or replace the original global plugin.
