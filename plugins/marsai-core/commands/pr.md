---
description: "Opens a reviewable pull request, with description, evidence and merge danger. On a PR that already exists, rewrites the description."
argument-hint: "[draft]"
---

Load and follow the `marsai-core:open-pr` skill, with these arguments: $@

```
/marsai-core:pr          # opens the PR for the current branch
/marsai-core:pr draft    # opens it as a draft
```
